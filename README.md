# 🎧🍜 무드픽 (Mood Pick)

지금 **기분**과 **상황**을 적으면, AI가 어울리는 **노래 3곡**과 **먹을 것 3가지**를 골라 주는 서비스입니다.
기술개발연구프로젝트 12주차 「내 서비스에 AI 넣기」 과제.

- 운영 주소: https://mood-pick-six.vercel.app
- AI: 오픈하사(Open HASA) `gemma-4-31b`, OpenAI 호환 `https://open.hasa.re.kr/v1/chat/completions`

## 동작 방식

```
화면(index.html) ─ POST /api/recommend ─▶ Vercel 함수(api/recommend.js)
                                          └ 키를 붙여 오픈하사 호출 → JSON 검사 → 링크 붙여 돌려줌
```

- **노래**: 곡명·가수 + 유튜브 검색 링크
- **맛집**: AI가 가게 이름을 지어내지 않도록 *메뉴*만 추천하고, 입력한 동네 + 메뉴로 **네이버 지도 검색** 링크 연결

## AI 자리와 지시문

| 요소 | 내용 |
|---|---|
| 역할 | 기분·상황에 맞춰 노래와 먹을 것을 추천하는 도우미 |
| 형식 | JSON 하나(노래 3, 메뉴 3), 이유는 한 문장 40자 이내 |
| 근거 | 사용자가 준 기분·상황만 |
| 금지 | 가게 이름 지어내기, 광고, 개인정보, 술·약물 권유, 의학 조언 |

지시문은 `lib/recommend.js`의 `SYSTEM_PROMPT`에만 있고, 사용자 입력은 별도 `user` 메시지로 보냅니다.

## 키 규칙

- 키는 **Vercel 환경 변수 `HASA_API_KEY`(Sensitive)** 에만 둡니다. 코드·README·대화창에 넣지 않습니다.
- 함수는 `process.env.HASA_API_KEY`에서만 읽고, 응답·로그에 출력하지 않습니다.
- 로컬 시험이 필요하면 `.env.example`을 `.env.local`로 복사해 값을 넣습니다(`.gitignore`로 Push 안 됨).

## 실패 안내

| 상황 | 응답 | 화면 안내 |
|---|---|---|
| 기분 없음 / 글자 수 초과 | 400 | 무엇을 고치면 되는지 |
| 키 없음 | 500 | 서비스 설정 문제, 운영자에게 알림 |
| 한도 초과 | 429 | 분당 10회·하루 500회, 1분 뒤 다시 |
| 20초 초과 | 504 | 다시 시도 버튼 |
| 이상한 답(JSON 아님) | 한 번 더 받고, 그래도 이상하면 502 | 다시 시도 |

## 비용·남용 막기

- 입력 길이 제한: 기분 30자, 상황 300자, 동네 30자
- 같은 입력은 10분 동안 저장해 다시 사용(캐시)
- 버튼은 답이 올 때까지 비활성(연타 막기)
- `max_tokens: 700`

## 개인정보

- 화면에 "이 글은 AI에 보내집니다, 저장하지 않습니다, AI 추천은 틀릴 수 있습니다" 안내
- 전화번호·이메일·학번 형태는 AI에 보내기 전에 `[전화번호]` 등으로 가림
- 입력과 답을 저장하지 않음(10분 메모리 캐시만, 함수가 꺼지면 사라짐)

## 시험

```bash
npm test   # = node --test
```

오픈하사를 가짜 `fetch`로 바꿔 **정상 / 400 / 키 없음 / 429 / 시간 초과 / 이상한 답 / 개인정보 가리기 / 함수 405·500** 8개를 시험합니다. 실제 키와 네트워크는 쓰지 않습니다.
